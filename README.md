# خرائط رؤية الهلال حسب معيار SAO جنوب أفريقيا

**الإصدار:** v9.6.3

نسخة GitHub Pages من برنامج خرائط رؤية الهلال حسب معيار SAO جنوب أفريقيا، وتتضمن العرض ثنائي الأبعاد والكرة الأرضية ثلاثية الأبعاد وطبقة تصنيفات SAO.

## النشر على GitHub Pages

1. أنشئ مستودع GitHub جديداً أو افتح المستودع المطلوب.
2. ارفع الملفات الموجودة في هذه الحزمة إلى جذر المستودع، ويجب أن يبقى اسم الصفحة الرئيسية `index.html`.
3. افتح **Settings → Pages**.
4. ضمن **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
6. بعد اكتمال النشر سيظهر رابط الموقع في صفحة GitHub Pages.

## الملفات

- `index.html` — البرنامج الكامل الجاهز للعمل على GitHub Pages.
- `.nojekyll` — يمنع GitHub Pages من معالجة الموقع عبر Jekyll.
- `README.md` — تعليمات النشر.

البرنامج مستقل داخل صفحة HTML واحدة؛ خريطة العالم والخطوط والموارد اللازمة مضمنة داخلها ولا يحتاج إلى ملفات أصول خارجية.
